
# 📸 Clone do Instagram

### Interface Front-End com HTML, CSS e JavaScript

O **Clone do Instagram** é um projeto Front-End inspirado na interface da rede social Instagram, desenvolvido para praticar estruturação de páginas, estilização e responsividade.

## 🎯 Problema e Solução

**Problema:** desenvolver interfaces semelhantes às de aplicações reais exige organização visual, posicionamento de elementos e adaptação para diferentes dispositivos.

**Solução:** criação de uma interface inspirada no Instagram, reproduzindo elementos visuais da plataforma com HTML, CSS e JavaScript.

## 🚀 Funcionalidades

- Tela inicial inspirada no Instagram
- Área de login estilizada
- Ícones e elementos visuais personalizados
- Layout moderno e responsivo
- Adaptação para diferentes tamanhos de tela

## 🛠️ Tecnologias

**Front-End**
- HTML5
- CSS3
- JavaScript
- DOM

## 💡 Desafio Técnico

O principal desafio foi reproduzir uma interface inspirada em uma aplicação real, trabalhando posicionamento dos elementos, estilização com CSS e responsividade para diferentes dispositivos.
